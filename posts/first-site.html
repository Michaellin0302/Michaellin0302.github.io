用 GitHub Pages 白嫖第一个网站

2026-11-21|Michaellin0302|约 4 分钟|系列:建站记 · 第 3 篇

有了账号,下一步就是把网站架起来。GitHub Pages 最迷人的地方在于:仓库即网站,推代码就上线。

原理:仓库就是服务器

GitHub 给每个账号一个特殊仓库:用户名.github.io。往里面放一个 index.html,它就会自动变成你的网站:

仓库:Michaellin0302/Michaellin0302.github.io
网址:https://michaellin0302.github.io/
规则:仓库里的 index.html 就是首页,目录结构就是网址结构

不用买服务器、不用配环境、不用管 HTTPS——证书都是自动签发的。

我的实操步骤

  1. 本地建一个文件夹,写好 index.html(当时第一版只有导航、列表、页脚三个部分)
  2. 初始化本地 Git 仓库并提交:
git init -b main
git add -A
git commit -m "Initial commit: 我的第一个网站"
  1. 用 GitHub CLI 一条命令创建远程仓库并推送:
gh repo create Michaellin0302.github.io --public --source . --push
  1. 等 1~2 分钟,Pages 自动构建,网站就上线了

「push 即发布」的工作流

上线之后,日常更新就三步:

git add -A
git commit -m "新文章:标题"
git push        # 约 1 分钟后自动生效

这就是为什么我不用任何建站框架——改几个 HTML 文件、推上去,比学一套框架的构建流程直接得多。

它的边界:只能托管静态内容

GitHub Pages 只能给静态文件(HTML/CSS/JS/图片)。如果你的网站需要用户登录、数据库、后端 API,就需要真正的服务器。但博客、作品集、文档站这些场景,静态完全够用,而且永远免费。

⚠️国内访问 github.io 时好时坏,解决方案见第 4 篇;绑自己的域名能明显改善,见第 5 篇。

从写下第一行 HTML 到全世界都能访问,只花了几分钟。这就是开源世界最浪漫的地方。
