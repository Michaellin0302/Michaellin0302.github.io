绑上自己的域名:my.midodo.tech

2026-11-21|Michaellin0302|约 4 分钟|系列:建站记 · 第 5 篇

michaellin0302.github.io 虽然免费,但又长又难记。这篇记录我怎么把已有域名 midodo.tech 的子域名 my.midodo.tech 绑到博客上——全程只用了一条 DNS 命令。

主域名 vs 子域名:解析方式不一样

绑域名之前要先搞清两种情况:

  • 子域名(如 my.midodo.tech):加一条 CNAME 记录指向 用户名.github.io 即可,最简单
  • 主域名(如 midodo.tech):不能用 CNAME(DNS 规范限制),要加 4 条 A 记录指向 GitHub Pages 的固定 IP:185.199.108.153、185.199.109.153、185.199.110.153、185.199.111.153
💡我选了子域名方案:一条记录搞定,主域名的其他解析(邮箱等)完全不受影响。

用阿里云 CLI 加解析:一条命令

域名在阿里云,装好 aliyun 命令行工具并配置好凭证后,加一条解析就是一行命令:

aliyun alidns AddDomainRecord \
  --DomainName midodo.tech \
  --RR my \
  --Type CNAME \
  --Value michaellin0302.github.io \
  --TTL 600

返回一个 RecordId 就成功了。用 nslookup my.midodo.tech 验证,能解析到 GitHub 的 IP 就说明 DNS 生效。

GitHub 侧两步

  1. 仓库根目录加一个 CNAME 文件,内容一行:my.midodo.tech
  2. 仓库 Settings → Pages 里填上自定义域名(或者用 API:PUT /repos/用户名/仓库/pages)

之后 GitHub 会自动做两件事:把 github.io 地址 301 重定向到新域名;为你的域名自动签发 Let's Encrypt HTTPS 证书。

唯一需要耐心的地方

DNS 生效很快(TTL 600 也就是 10 分钟内),但 HTTPS 证书签发是异步的,一般 10~30 分钟,偶尔要一两个小时。判断方法:证书透明度日志 crt.sh 查不到你的域名 = 还没签好;浏览器访问报 TLS 握手失败多半也是这个原因——等等就好,无需任何操作。

成本结算

  • 域名:.tech 属于便宜档,一年几十元(买域名需实名认证)
  • 解析:阿里云免费 DNS 即可
  • 托管 + 证书:GitHub Pages 白送

解析生效的那一刻,输入 my.midodo.tech 看到自己的博客,成就感拉满。
