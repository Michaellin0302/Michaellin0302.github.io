这个博客是怎么搭的

没有任何框架,纯手写静态 HTML + CSS,托管在 GitHub Pages 上,完全免费:

  • 域名:michaellin0302.github.io(GitHub 白送)
  • 服务器:GitHub Pages(白送)
  • 代码:git push 即发布,约 1 分钟生效

以后怎么写新文章

  1. 复制 posts/hello-world.html 改名,比如 posts/my-first-post.html,修改标题、日期和正文
  2. 在 index.html 的文章列表里加一行:
<li>
  <span class="date">2026-12-01</span>
  <a href="posts/my-first-post.html">文章标题</a>
</li>
  1. 提交推送,自动上线:
git add -A
git commit -m "新文章"
git push
