这个站是怎么搭的

没有任何框架,纯手写静态 HTML + CSS,托管在 GitHub Pages 上,完全免费:

  • 域名:my.midodo.tech(已有的 midodo.tech 加了一条解析)
  • 服务器:GitHub Pages(白送)
  • HTTPS 证书:Let's Encrypt 自动签发(还是白送)
  • 代码:git push 即发布,约 1 分钟生效

以后怎么写新文章

  1. 复制 posts/hello-world.html 改名,比如 posts/my-first-post.html,修改标题、日期和正文
  2. 在 index.html 的文章卡片里复制一块 <a class="card-wrap"> 并修改
  3. 提交推送,自动上线:
git add -A
git commit -m "新文章:标题"
git push

慢慢写,把这里当成自己的技术笔记本。
