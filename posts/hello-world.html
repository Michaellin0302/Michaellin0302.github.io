Hello, World! 博客开通

2026-11-21|Michaellin0302|约 2 分钟|系列:建站记 · 第 1 篇

博客正式开通了 🎉 这是「建站记」系列的第 1 篇,整个系列会把从零到上线的每一步都写清楚,给同样想搭博客的你当参考。

这个站是怎么搭的

没有任何框架,纯手写静态 HTML + CSS,托管在 GitHub Pages 上,完全免费:

  • 域名:blog.midodo.tech(已有域名加一条解析,详见第 5 篇)
  • 服务器:GitHub Pages(白送)
  • HTTPS 证书:Let's Encrypt 自动签发(还是白送)
  • 代码:git push 即发布,约 1 分钟生效
💡算一笔账:域名一年几十块,其他全部免费。一个完全属于自己的网站,成本大约等于两杯奶茶。

为什么要写博客

  1. 学习最怕"看懂了"——能写出来给别人看,才算真的懂
  2. 给自己留档——踩过的坑记下来,下次不用再踩一遍
  3. 作品即简历——一个持续更新的博客,比任何自我介绍都可信

这个系列怎么读

整个系列按真实时间线排列:

  1. 本文:博客开通
  2. 从零开始:注册我的 GitHub 账号
  3. 用 GitHub Pages 白嫖第一个网站
  4. 国内访问 GitHub 的坑与填坑工具
  5. 绑上自己的域名:blog.midodo.tech

接下来

慢慢写,把这里当成自己的技术笔记本。

Stay hungry, stay foolish.
