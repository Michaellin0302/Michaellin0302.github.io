从零开始:注册我的 GitHub 账号

2026-11-21|Michaellin0302|约 3 分钟|系列:建站记 · 第 2 篇

一切从一个账号开始。这篇记录我注册 GitHub 的完整过程和几个当时没注意到的小细节。

GitHub 是什么,为什么要有它

GitHub 是全球最大的代码托管平台,可以理解为「程序员的云盘 + 协作办公室」:

  • 备份代码:每次修改都有记录,随时回退,不怕电脑挂掉
  • 免费额度非常够用:公开仓库无限量,私有仓库也免费,连 CI/CD 都送每月 2000 分钟
  • 作品集:主页贡献记录一目了然,找工作时这就是你的第二份简历
  • 开源世界的大门:Linux、VS Code、TensorFlow 都住在这里

注册步骤(5 分钟搞定)

  1. 打开 github.com/signup(国内访问慢的话,先开 Watt Toolkit 加速,详见第 4 篇)
  2. 填邮箱 → 设密码 → 起用户名
  3. 去邮箱点验证链接
  4. 完成,一分钱不花

用户名千万别乱起

这是我当时没意识到的一点:用户名会出现在你的网址里。比如我的用户名是 Michaellin0302,那么:

https://michaellin0302.github.io/    ← 以后个人网站就用这个
https://github.com/Michaellin0302    ← 主页地址

改用户名虽然可以,但旧链接会失效、别人收藏的地址会 404。所以第一原则:起个能公开示人的正经名字,拼音或英文都行,避免一串无意义字符。

注册完第一件事

账号到手别闲着,推荐立刻做两件事:

  1. 建第一个仓库——直接开始建站(见第 3 篇),实战永远是最好的学习
  2. 完善 Profile——头像、简介、位置,让别人一眼认识你
💡GitHub 免费版早就支持私有仓库了,不想公开的代码也可以放心放。

有了账号,就有了一切的可能。
