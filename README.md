# 林志强的奇思妙想

暗色极客风单页名片,纯静态 HTML/CSS,零依赖、零外部资源,托管在 GitHub Pages,桌面/平板/手机自适应。

线上地址:<https://midodo.tech>

## 结构

```
├── index.html             主页(打字机大标题/自我介绍/技能进度/第一天/找到我)
├── 404.html               404 页
├── assets/
│   └── style.css          全站样式(含响应式断点)
├── CNAME                  自定义域名 midodo.tech
└── README.md
```

## 更新方式

改完文件后:

```bash
git add -A
git commit -m "更新说明"
git push
```

约 1 分钟后自动上线。
